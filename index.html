⚙ Conexão com o n8n

✕

Com Supabase configurado, o CRM lê/grava no banco em tempo real e sincroniza com o fluxo n8n. Sem isso, funciona local (localStorage). Rode antes o supabase-crm_clientes.sql.

Preenchendo isto (e deixando o Supabase vazio), o CRM lê os clientes gravados pelo próprio fluxo n8n e atualiza os cards sozinho (a cada 5s). Fluxo: planilha → n8n → CRM.

O botão ⚡ Ativar no n8n envia todos os clientes da coluna Cliente Ativado para esse webhook (um JSON com name, phone, filial, channel_id, hsm por cliente). Veja CONECTOR-N8N.md para colar o nó Webhook no seu fluxo.
